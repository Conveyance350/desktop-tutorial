# 依頼
添付の作業観察シートを、Surface Go 4で使うHTMLアプリに作り替えたい。
まずシートを読み取り、下の「進め方」の手順1・2だけを実施してください。

# 背景
- 構内物流の課で、Surface Go 4を使って作業観察をしている
- 現在は○×をプルダウンで判定し、×の場合に指導コメントを入力している
- タッチ操作では入力しにくく、コメントの中身も薄くなりがち

# 決定済みの方針
1. ○×は大きなタップボタンで1タップ判定にする
2. ×を押すと、その項目の定型コメント（事実：何が起きたか）をボタンで選べる。選択肢には必ず「その他」を入れる
3. 観察者の記述力を育てるため、次の2欄は自由記述にして入力必須にする
   - 「なぜ起きたと思うか」
   - 「何と指導したか」
4. 自由記述はタッチキーボードの手書き入力も想定する（音声入力は使わない前提）
5. 記録はCSVで出力し、週1回の振り返りで課長がフィードバックする
6. 「その他」が多い項目は、定型コメントを見直すきっかけにする

# 進め方
1. シートから観察項目の一覧を抜き出す
2. 項目ごとに定型コメント案を3〜5個出す（現場の言葉を使う）
3. 私が確認したら、HTMLアプリを作成する

# アプリ作成ルール
- HTML・CSS・JavaScriptを1ファイルにまとめ、.htmlファイルで出力する
- Google Fontsなどの外部サービスや外部ライブラリは使わない（オフラインで動くこと）
- Surface Go 4（10.5インチ・タッチ操作）向けに、大きなボタン・大きな文字・少ない操作・日本語表記にする
- 色：文字 #333333、補足・罫線 #7F7F7F、背景は白、強調 #2F5597、NG・注意 #C00000、OK・完了 #548235
- 色で状態を示すときは、必ず「OK」「NG」などの文字も併記する
- グラデーション・影・角丸・絵文字・アイコンは使わない
- フォント：Meiryo UI（ない場合はメイリオ）
- コードの後に「使い方」を3行以内で添える

# 回答ルール
- 結論から、端的に書く。前置きや締めの言葉は不要
- 不明な点は推測で補って進め、推測した点を最後に1〜3行で示す
